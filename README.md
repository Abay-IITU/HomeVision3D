
# 🎮 GameGear — Online Gaming Store

## 📌 Project Description
GameGear is an online store for gaming equipment and accessories.
The platform allows users to browse gaming products, search and filter items,
add products to a shopping cart, place orders, and manage their profiles.

## 🎯 Project Objectives
- Create a user-friendly online gaming store.
- Provide convenient product search and filtering.
- Implement shopping cart and order management.
- Develop an administrator panel for managing products.
- Use Java Spring Boot and PostgreSQL.

## 👥 Target Users
- Gamers
- Computer enthusiasts
- Gaming equipment buyers
- Store administrators

## ⚙️ Technologies
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Thymeleaf
- PostgreSQL
- HTML, CSS, JavaScript
- Maven

## ✨ Main Features
- User registration and login
- Product catalog
- Product search and filtering
- Product details
- Shopping cart
- Order management
- User profile
- Admin product management

## 🏗️ Architecture
Controller → Service → Repository → Database
